# 拍照選尺碼（foot-size-advisor）

客人腳踩 A4 紙拍一張照片，網頁自動量出腳長腳寬，給出這雙鞋的尺碼建議。
純靜態網頁，部署在 GitHub Pages，照片只在客人手機上處理，不會上傳。

## 網址用法

```
https://<GitHub 帳號>.github.io/foot-size-advisor/?sku=11802053&back=https://www.dk-shoes.com.tw/SalePage/Index/11802053
```

| 參數 | 說明 |
|------|------|
| `sku` | 對應 `data/sizes/<sku>.json` 的尺碼表，目前用 91APP 銷售頁編號 |
| `back` | 結果頁「回商品頁」按鈕的網址，沒帶就不顯示按鈕 |
| `debug=1` | 顯示偵測過程的遮罩與數值，調參數用 |

## 客人看到的流程

1. **引導卡片**：開始 → 紙放深色地板 → 紙貼牆、腳跟貼牆 → 手機在腳尖上方拍。一張卡片只做一件事。
2. **拍照或選相簿照片**。
3. **自動找紙**：找不到時直接說原因和怎麼修（地板太白、紙角沒入鏡、紙被擋住），可以重拍或自己拖圓點標紙角。
4. **確認紙角**：四個圓點可拖動。
5. **自動量腳**：有問題時說原因（腳跟沒貼齊、腳太靠邊、腳尖碰紙邊、找不到腳）。
6. **確認腳**：腳跟、腳尖、兩個腳寬點可拖動，上方即時顯示腳長腳寬。
7. **結果**：建議尺碼、原因、整張尺碼表標出建議的那列。可以再量另一隻腳，兩腳取大的。

## 新增商品

在 `data/sizes/` 新增 `<sku>.json`：

```json
{
  "sku": "11802053",
  "name": "商品名稱",
  "verified": true,
  "width_rule": { "enabled": false, "margin_mm": 0 },
  "sizes": [
    { "label": "23號", "foot_min": 225, "foot_max": 235, "shoe_length": 245, "shoe_width": 98 }
  ]
}
```

- 單位一律 mm。`foot_min` 含、`foot_max` 不含。
- `shoe_length`、`shoe_width` 可省略，省略時結果表不顯示這兩欄。
- `width_rule.enabled` 為 `true` 時，腳寬 ≥ 該號鞋寬 + `margin_mm` 就建議大一號，需要每個尺碼都有 `shoe_width`。
- 腳長離區間邊界 3 mm 以內，會同時列出相鄰兩個尺碼。

## 測試

本機開伺服器（ES module 不能用 `file://` 開）：

```bash
python -m http.server 8765
```

- `http://localhost:8765/test/run.html`：自動測試。幾何計算、尺碼判斷，以及 13 種模擬照片（傾斜、橫拍、腳跟在上、暖光、深色襪、白地板、紙角被切等）跑完整流程。
- `http://localhost:8765/test/photos.html`：實拍照片準確度。選多張照片，檔名帶真值（例如 `245x98_赤腳.jpg`），會算出自動抓紙成功率、腳長腳寬誤差，以及建議的修正值。

模擬照片的量測誤差都在 1 mm 內，但真實照片的膚色、陰影、JPEG 壓縮、腳的立體厚度都不同，**上線前一定要用實拍照片跑 `photos.html` 驗收**。

## 調參數

所有門檻集中在 `js/config.js`，常用的：

| 參數 | 用途 |
|------|------|
| `LENGTH_OFFSET_MM`、`WIDTH_OFFSET_MM` | 系統性誤差修正，照 `photos.html` 的建議值調 |
| `SEG_DARK_T`、`SEG_CHROMA_T` | 腳和紙的分割門檻，腳抓不完整或把影子當腳時調整 |
| `PAPER_ASPECT_TOL_AUTO` | 自動抓紙的長寬比容許範圍 |
| `BOUNDARY_MM` | 離尺碼邊界多近時同時列兩個尺碼 |

## 原理

1. 縮圖後找最亮、最像四邊形的區塊當 A4 紙，再回原圖沿四條邊找明暗交界擬合直線，交點就是紙角。
2. 用四個角做透視校正，把紙拉正成 210 × 297 mm，斜拍的變形一起消掉。
3. 在校正圖上，比紙暗很多或顏色偏離紙張的區域視為腳，紙的明暗漸層用二次曲面擬合吸收。
4. 腳跟切齊紙邊時，腳跟點在紙的下緣；腳尖點是沿腳軸最遠的點；腳寬在腳跟算起 55%~80% 的腳掌區段，沿垂直腳軸方向量。腳斜放也能量。

影像處理全部自己寫在 `js/cv.js`、`js/geometry.js`，沒有用 OpenCV.js，整個網站不到 100 KB，LINE 內建瀏覽器用 4G 也能馬上打開。

## 已知限制

- **分不出 A4 和 B5**：A 系列和 B 系列紙張長寬比相同，程式無法用比例分辨。客人用 B5 會量大約 15%，通常會落到「沒有適合尺碼」或被合理性檢查擋下。
- 白色地板、白襪會抓不到紙或腳，已有引導提示。
- 腳有厚度，手機沒在腳尖正上方時腳長會偏差幾 mm。
- LINE 內建瀏覽器常擋即時相機，所以用系統相機拍照後上傳，無法在拍照畫面疊引導框。

## 檔案結構

```
index.html            畫面（引導卡片、確認、結果）
css/style.css
js/app.js             流程控制
js/guidance.js        拍完照的問題引導文字與示意圖
js/config.js          所有門檻值
js/cv.js              影像基本運算
js/geometry.js        單應矩陣、凸包、直線擬合、長寬比估計
js/paper.js           A4 偵測、紙角精修、透視校正
js/foot.js            腳部分割、腳跟方向判斷
js/measure.js         自動標記點、腳長腳寬計算
js/pipeline.js        照片 + 紙角 → 量測結果
js/sizing.js          尺碼表載入與建議
js/ui-adjust.js       可拖動圓點的畫布（含放大鏡）
js/image.js           讀照片、畫布轉換
data/sizes/*.json     各商品尺碼表
test/run.html         自動測試
test/photos.html      實拍準確度測試
開發計畫.md            原始規格與實作變更紀錄
```
