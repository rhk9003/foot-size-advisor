# 實拍測試照片

這個資料夾放真實的量腳照片，用來驗收準確度與校正參數。

## 登記方式

照片放進這個資料夾，在 `index.json` 登記人工用尺量的真值（單位 mm）：

```json
[
  { "file": "01_赤腳_木地板.jpg", "length_mm": 245, "width_mm": 98, "note": "正上方拍" },
  { "file": "02_深色襪_磁磚.jpg", "length_mm": 262, "width_mm": 103, "note": "斜拍約 15 度" }
]
```

然後開 `test/photos.html`，按「跑資料夾」。

## 建議涵蓋的情境（至少 20 張）

- 地板：深色地板、木地板、白色磁磚（預期抓不到紙）
- 腳：赤腳、深色薄襪、白襪（預期分割困難）
- 角度：正上方、斜拍約 15 度、斜拍約 30 度
- 位置：腳跟貼齊紙邊、腳跟沒貼齊
- 光線：室內燈、窗邊自然光、有影子

## 真值怎麼量

- 腳長：腳跟貼牆站好，量牆到最長腳趾前端的距離。
- 腳寬：腳掌最寬處，兩側用書本夾住，量兩本書之間的距離。

## 隱私

照片含個人腳部影像。部署到 GitHub Pages 時這個資料夾會公開，請只放同意公開的照片，
或把照片留在本機、不要 commit。
